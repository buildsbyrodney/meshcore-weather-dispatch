# MeshCore Weather Dispatch v1.0.0-rc.2

`v1.0.0-rc.2` is the second public release candidate. It is intended for trusted-LAN Raspberry Pi, Debian, or Ubuntu deployments operated by an authenticated administrator.

## Verified clean installation

This release was successfully installed and operated on a freshly flashed Raspberry Pi OS 64-bit system with a USB MeshCore Companion. After the installer completes, grant the service account USB serial access and reboot before opening the web interface:

```bash
sudo usermod -aG dialout weatherdispatch
sudo reboot
```

The reboot activates the new `dialout` membership and ensures Nginx loads the Weather Dispatch site rather than its default welcome page. Access the console at `http://<Pi-IP>/`.

## Changes since rc.1

- The managed Git checkout is now created and cloned by `weatherdispatch`, preserving Git's ownership protections without a `safe.directory` exception. Both install and update scripts are executable in Git.
- Initial administrator setup confirms the password and retries short or mismatched entries. Passwords require at least six characters; secure hashing, authenticated sessions, CSRF protection, audit identity, and account-change current-password verification remain in place.
- Installation documentation now covers USB Companion serial permissions, rebooting after install, and troubleshooting for permission errors and Nginx's default page.

## Safety and operating model

- NWS polling never transmits automatically. Every weather or test message needs an authenticated operator, explicit action, and final confirmation.
- Manual dispatch still requires an eligible alert, signed preview, expiry/replay checks, selected Companion and channel verification, UTF-8 size validation, and an atomic dispatch claim.
- Companion command acceptance is recorded as radio acceptance, not proof of over-the-air delivery.

## Upgrade notes

Existing managed installations can run:

```bash
sudo /opt/meshcore-weather-dispatch/scripts/update.sh
```

The updater creates timestamped backups and preserves the application secret, administrator credentials, SQLite history, counties, Companion selection, transmit channel, and existing service overrides.

## Known limits

- HTTP is appropriate only on a trusted LAN; configure HTTPS before remote or untrusted access.
- No autonomous sends, polygon-aware receiver handling, region-scoped flooding, delivery confirmation, or automatic cancellation broadcasts are implemented.
- Validate the exact Companion firmware and installed `meshcore` library pairing on a private test channel before operational use.
