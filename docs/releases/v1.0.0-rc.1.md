# MeshCore Weather Dispatch v1.0.0-rc.1

`v1.0.0-rc.1` is the first public release candidate. It is intended for a trusted-LAN Raspberry Pi or Debian/Ubuntu deployment operated by an authenticated administrator.

## Highlights

- Manual-only NWS warning dispatch: polling never sends a radio message.
- NWS revisions, cancellations, expiry, selected county filtering, and durable audit history.
- Read-only Companion discovery plus explicit device, channel, channel-management, and device-name administration.
- Test Alerts and Test Messaging for controlled private-channel bench testing.
- Nginx on HTTP port 80, Gunicorn bound only to `127.0.0.1:8080`, and a single-worker systemd service.
- Installer-generated session secret and initial administrator account, with guarded updates and timestamped SQLite backups.

## Upgrade notes

Use `sudo /opt/meshcore-weather-dispatch/scripts/update.sh` from an existing managed installation. The updater backs up SQLite and managed configuration before changing the checkout and preserves the environment secret, account, county coverage, alert/audit history, Companion selection, and TX channel. It retains an existing disabled manual-transmission setting.

## Known limits

- HTTP is for a trusted LAN only; configure HTTPS before remote or untrusted access.
- Companion command acceptance is not evidence of mesh delivery.
- No autonomous sends, polygon-aware receiver handling, region-scoped flooding, or automatic cancellation broadcasts are implemented.
- Validate the exact Companion firmware and `meshcore` library pairing on private bench hardware before operational use.
